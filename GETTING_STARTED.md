# Пошаговая инструкция: запуск проекта через Claude Code

Этот файл — твой гид. Дойди до конца — получишь работающий бот, тесты,
git-историю и понимание, как итеративно развивать проект через Claude Code.

---

## Шаг 0. Что должно быть готово до старта

- **Node.js 18+** — проверь: `node --version`. Если нет — поставь LTS
  с https://nodejs.org.
- **Python 3.11+** — проверь: `python3 --version`.
- **Аккаунт Anthropic** — нужен для логина в Claude Code.
- **Аккаунты для ключей** (можно создать позже на шаге 5):
  - https://the-odds-api.com (обязательно)
  - Telegram (нужен @BotFather, тоже обязательно)
  - https://www.football-data.org/client/register (опционально)

---

## Шаг 1. Установка Claude Code

В терминале:

```bash
npm install -g @anthropic-ai/claude-code
claude --version
```

Если после установки `claude` не находится — перезапусти терминал.

---

## Шаг 2. Подготовь папку проекта

Распакуй архив `match_anomaly_bot.zip` в удобное место, например:

```bash
mkdir -p ~/projects
cd ~/projects
unzip ~/Downloads/match_anomaly_bot.zip
cd match_anomaly_bot
ls -la
```

Должны увидеть: `src/`, `data/`, `logs/`, `README.md`, `CLAUDE.md`,
`GETTING_STARTED.md` (этот файл), `.env.example`, `.gitignore`,
`requirements.txt`.

---

## Шаг 3. Запусти Claude Code

```bash
claude
```

При первом запуске откроется браузер для авторизации через Anthropic-аккаунт.
После логина ты в интерактивной сессии в этой папке. Claude Code сам
прочитает `CLAUDE.md` и поймёт контекст проекта.

Полезные команды внутри сессии (со слэшем):

| Команда | Что делает |
|---|---|
| `/help` | Все команды |
| `/clear` | Очистить контекст (когда меняешь тему) |
| `/exit` | Выйти |

---

## Шаг 4. Инициализируй git и сделай первый коммит

Скажи Claude:

> Инициализируй git-репозиторий и сделай первый коммит «initial import».
> Проверь, что .env, data/, logs/ и .venv/ не попадают под трекинг.

Claude выполнит `git init`, проверит `.gitignore`, добавит файлы и закоммитит.
Перед каждой командой будет спрашивать подтверждение — это нормально,
читай и нажимай y.

---

## Шаг 5. Получи ключи API

Прежде чем запускать — нужны ключи. Это руками, без Claude:

**The Odds API** (обязательно):
1. Открой https://the-odds-api.com
2. «Get API Key» → введи email
3. Скопируй ключ из письма

**Telegram bot** (обязательно):
1. В Telegram напиши `@BotFather`
2. Команда `/newbot` → следуй инструкциям → получишь токен
3. Найди своего нового бота в поиске, напиши ему любое сообщение
4. Открой в браузере: `https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates`
5. В JSON найди `"chat":{"id":...}` — это твой `TELEGRAM_CHAT_ID`

**football-data.org** (опционально, но рекомендую):
1. Открой https://www.football-data.org/client/register
2. Зарегистрируйся → ключ придёт на почту

## Шаг 6. Установи зависимости и заполни .env

В сессии Claude Code:

> Создай виртуальное окружение в .venv, активируй его и поставь
> зависимости из requirements.txt. Потом скопируй .env.example в .env.

Claude выполнит команды. После — открой `.env` любым редактором и впиши
свои ключи. Или скажи Claude:

> Открой .env и помоги мне подставить ключи — я тебе их продиктую.

(Если решишь так — потом не забудь проверить, что `.env` точно
не закоммитился — он в `.gitignore`, должно быть ок.)

---

## Шаг 7. Первый запуск

> Запусти `python -m src.main` и покажи логи. Если будет ошибка —
> разбери traceback и предложи фикс.

Если всё ок — в Telegram придёт стартовое сообщение от бота, и через
несколько секунд начнёт работать первый цикл опроса Odds API.

Чтобы остановить — Ctrl+C в терминале.

---

## Шаг 8. Проверь команды бота

В Telegram своему боту:

- `/help` — список команд
- `/stats` — статистика (после первого цикла)
- `/recent` — последние аномалии
- `/thresholds` — текущие пороги
- `/elo Arsenal` — рейтинг команды (если она встречалась в матчах)

## Шаг 9. Первая полезная задача — тесты

Это идеальная задача для Claude Code: чистая логика, нет сети,
легко проверить.

> Напиши pytest-тесты для src/detectors.py. Покрой все 5 детекторов:
> spread, drift, synchronized, model_gap, exotic_spread. Используй
> синтетические объекты MatchOdds — без сетевых запросов и без
> реальной БД (sqlite в памяти ок). Для каждого детектора: один
> позитивный кейс (аномалия должна сработать) и один негативный
> (на честных данных молчит). Положи в tests/test_detectors.py,
> добавь pytest в requirements.txt, запусти тесты и покажи результат.

Claude напишет тесты, запустит, покажет вывод. Если что-то падает —
поправит. После зелёной сборки:

> Сделай коммит «add tests for detectors».

## Шаг 10. Привычки для дальнейшей работы

Дальше развивай проект маленькими задачами. Несколько правил, которые
сэкономят нервы:

**Маленькие задачи, не «допиши всё».** Хорошо: «добавь в pipeline.py
фильтр на матчи в ближайшие 48 часов и тест». Плохо: «улучши проект».

**Читай diff перед apply.** Claude Code показывает изменения файлов
до записи. Просматривай — это занимает секунды и спасает от тихих
сюрпризов.

**Коммить осмысленными порциями.** После каждой задачи проси сделать
коммит. Будет история, легко откатиться.

**`/clear` между темами.** Сменил направление работы (с тестов на
рефакторинг) — очисти контекст, чтобы модель не путалась и не жгла
токены на старом контексте.

**Дай Claude запускать тесты.** Хорошая фраза в задаче: «после
изменений запусти `pytest -q` и покажи результат». Тогда он сам
поймает регрессии и поправит.

**Не ленись с `CLAUDE.md`.** Когда что-то узнаёшь о проекте — особенность,
ограничение, договорённость о стиле — попроси добавить это в `CLAUDE.md`.
В следующих сессиях это сэкономит контекст.

## Что делать дальше — приоритеты

После шага 9 у тебя работающий бот с тестами на ядре. Следующие задачи
по приоритету (взято из `CLAUDE.md`):

1. Фильтр «матчи в ближайшие N часов» в `pipeline.py` — экономит запросы
   к Odds API.
2. Команда бота `/mute <hours>` — отключать алерты на ночь / в отпуске.
3. Загрузка стартовых Elo с clubelo.com — детектор `model_gap` заработает
   сразу, без месяца разогрева.
4. Накопить 2+ месяца истории и оценить точность каждого детектора по
   результатам матчей.
5. ML-слой (XGBoost / Isolation Forest) поверх правил — когда будет
   размеченная история.

## Если что-то идёт не так

- **`claude` не находится после `npm install`** — перезапусти терминал
  или проверь, что `npm bin -g` в PATH.
- **Бот не отвечает на команды** — проверь `TELEGRAM_CHAT_ID`, должен
  совпадать с чатом, в котором пишешь.
- **«401 Unauthorized» от Odds API** — ключ неверный или закончились
  запросы. Проверь на https://the-odds-api.com/dashboard.
- **Очень много алертов в первые часы** — нормально, пороги стоит
  поднять. Скажи Claude: «увеличь все пороги в .env на 50%, объясни
  что поменялось».
- **`model_gap` шумит** — ожидаемо без `FOOTBALL_DATA_KEY` или в первые
  недели. Подними `MODEL_GAP_THRESHOLD=1.0` в `.env` чтобы фактически
  отключить детектор, пока Elo не наберётся.

Удачи. Проект пишется итеративно — не пытайся сделать всё идеально
с первого раза.
