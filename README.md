# Match Anomaly Detector

Детектор аномалий в букмекерских коэффициентах с уведомлениями в Telegram.

**Важно:** инструмент образовательный и аналитический. Аномалия в линии ≠ договорной матч. Чаще это инсайды о травмах, тактике или просто рыночный шум. Не используй как сигналы для ставок — это убыточная стратегия по причинам, обсуждённым ранее (букмекеры реагируют быстрее, ставки аннулируют, лимиты режут).

## Что делает

1. Раз в `POLL_INTERVAL_MINUTES` опрашивает The Odds API и забирает коэффициенты на ближайшие футбольные матчи.
2. Прогоняет матчи через **5 детекторов аномалий**:
   - **`spread`** — расхождение между букмекерами на 1X2
   - **`drift`** — резкое движение линии относительно открытия
   - **`synchronized`** — синхронные движения у нескольких букмекеров за один интервал (умные деньги)
   - **`model_gap`** — отклонение рыночного коэффициента от Elo-модели
   - **`exotic_spread`** — расхождение на тоталах и форах
3. Если хотя бы один детектор сработал — отправляет алерт в Telegram (с дедупликацией: один и тот же сигнал по матчу не приходит чаще раза в 2 часа).
4. Раз в сутки подтягивает результаты сыгранных матчей с football-data.org и обновляет Elo-рейтинги команд.
5. Отвечает на команды бота: статистика, последние аномалии, текущие пороги, Elo-рейтинг команды.

## Стек

- Python 3.11+
- `httpx` — HTTP-клиент
- `python-telegram-bot` v21+ — бот
- `APScheduler` — периодические задачи
- `SQLAlchemy` 2.0 + SQLite — хранилище
- `pydantic-settings` — конфиг через `.env`

## Установка

```bash
python -m venv .venv
source .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# Заполни .env: токены и chat_id
python -m src.main
```

## Получить ключи

1. **The Odds API** — https://the-odds-api.com (500 запросов/мес бесплатно).
2. **football-data.org** — https://www.football-data.org/client/register (опционально, для авто-обновления Elo).
3. **Telegram bot token** — напиши `@BotFather`, команда `/newbot`.
4. **Chat ID** — напиши своему боту любое сообщение, потом открой
   `https://api.telegram.org/bot<TOKEN>/getUpdates` — увидишь свой `chat.id`.

## Команды бота

| Команда | Что делает |
|---|---|
| `/start`, `/help` | Список команд |
| `/stats` | Общая статистика: всего аномалий, за 24ч, по детекторам |
| `/recent [N]` | Последние N аномалий (по умолчанию 5, максимум 20) |
| `/thresholds` | Текущие пороги детекторов |
| `/elo Arsenal` | Текущий Elo-рейтинг команды |

Команды принимаются только из чата с `TELEGRAM_CHAT_ID`.

## Стартовая загрузка Elo

По умолчанию все команды стартуют с рейтингом 1500 — детектор `model_gap` будет шуметь
1–2 недели, пока рейтинги не откалибруются по реальным результатам.
Чтобы он заработал сразу — загрузи готовые рейтинги с [clubelo.com](http://clubelo.com)
**один раз перед первым запуском бота**:

```bash
python -m src.elo_bootstrap            # берёт сегодняшнюю дату
python -m src.elo_bootstrap 2026-05-10 # или конкретную дату (YYYY-MM-DD)
```

Скрипт скачивает CSV (~2000 команд), нормализует имена и записывает в БД,
перезаписывая существующие записи. После запуска можешь проверить:

```
/elo Arsenal
/elo Bayern Munich
```

Если команда есть на clubelo.com — рейтинг появится немедленно.
Если бот уже работал и успел накопить обновления из результатов — `elo_bootstrap`
перезапишет их данными clubelo, что нормально (у них более точные начальные значения).

## Тюнинг анализа

Все пороги задаются в `.env`. Ниже список ключевых параметров, добавленных в последнем рефакторинге:

### Маржа-свободные вероятности и пороги в процентных пунктах

Детекторы `spread` и `drift` теперь работают с **margin-free вероятностями** и порогами
в процентных пунктах (pp), а не в относительных процентах. Это убирает влияние overround:
Betfair (0% маржа) и Bet365 (8% маржа) сравниваются честно.

| Параметр | Дефолт | Смысл |
|---|---|---|
| `SPREAD_PP_THRESHOLD` | `4.0` | Разрыв между букмекерами ≥ N pp — аномалия |
| `DRIFT_PP_THRESHOLD` | `5.0` | Движение линии за окно ≥ N pp — аномалия |
| `DRIFT_WINDOW_MINUTES` | `120` | Окно для сравнения дрейфа (мин) |
| `MIN_BOOKMAKERS_PER_MATCH` | `6` | Матчи с меньшим числом букмекеров пропускаются |

### Временны́е корзины (чувствительность по времени)

Чем ближе к матчу — тем ниже пороги. Настраивается двумя списками:

```env
TIME_BUCKETS_HOURS=[6,24,72]
TIME_BUCKET_MULTIPLIERS=[0.7,0.85,1.0,1.3]
```

Интерпретация: до 6 ч × 0.70 (агрессивно), 6–24 ч × 0.85, 24–72 ч × 1.00 (база),
> 72 ч × 1.30 (консервативно — ранние котировки шумные).

### Веса букмекеров

Sharp-конторы (Pinnacle, Betfair и пр.) двигают рынок первыми и получают бо́льший
вес при расчёте консенсусных вероятностей. `detect_synchronized` срабатывает только
если хотя бы одна sharp-контора входит в синхронно двинувшихся — follower-движения
без sharp игнорируются.

| Параметр | Дефолт | Смысл |
|---|---|---|
| `SHARP_BOOKMAKERS` | `["pinnacle","betfair_ex_eu","betfair_ex_uk","sbobet","matchbook"]` | Список sharp-контор |
| `SHARP_WEIGHT` | `1.0` | Вес sharp при weighted median |
| `DEFAULT_WEIGHT` | `0.4` | Вес остальных букмекеров |

### Старые параметры (deprecated, работают как fallback)

`SPREAD_THRESHOLD=0.08` и `DRIFT_THRESHOLD=0.15` сохранены для совместимости.
При наличии `SPREAD_PP_THRESHOLD`/`DRIFT_PP_THRESHOLD` используются новые.

## Расход API-запросов

На бесплатном тарифе The Odds API — 500 запросов/мес. При `POLL_INTERVAL_MINUTES=15` это:
`60 / 15 × 24 × 30 = 2880 запросов/мес` — **превысишь лимит**.

Варианты:
- Ставь `POLL_INTERVAL_MINUTES=90` (480 запросов/мес — впритык).
- Подпишись на платный тариф ($30/мес — 100k запросов).
- Опрашивай только в активные часы (можно дописать через CronTrigger в main.py).

## Что дальше

- Накопить 1–2 месяца истории и сравнить срабатывания с реальными результатами.
- Добавить фильтр "только матчи в ближайшие N часов" — чтобы не тратить запросы на матчи через неделю.
- Подгрузить начальные Elo-рейтинги с clubelo.com — детектор `model_gap` заработает сразу.
- Когда накопится размеченная история (срабатывание + что было дальше) — добавить ML-слой (XGBoost / Isolation Forest) поверх правил.
- Расширить за пределы футбола: теннис (особенно челленджеры — там больше аномалий), настольный теннис.
